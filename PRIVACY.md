# Политика конфиденциальности

**Приложение:** STeps (визуальный метроном / тренажёр базовых шагов)  
**Площадки:** мини-приложение ВКонтакте, Мессенджер, MAX, браузер, нативная оболочка  
**Дата публикации:** 12 сентября 2026 г.  
**Оператор:** разработчик приложения (далее — «мы»). Связь: в приложении **Настройки → Написать разработчику**.

Этот документ описывает, какие данные обрабатываются при использовании приложения и для каких целей. Пользуясь приложением, вы соглашаетесь с этой политикой.

## 1. Какие данные мы обрабатываем

### 1.1. На устройстве (остаются у вас)

- настройки интерфейса (тема, палитра, последовательность шагов, BPM и связанные предпочтения) — в локальном хранилище браузера / WebView;
- при работе с музыкой — технические данные выбранного файла и кэш на устройстве (если вы пользуетесь этим режимом).

Эти данные **не отправляются** на сервер как содержимое настроек, кроме случаев ниже.

### 1.2. На сервере приложения

- **анонимная статистика открытий:** площадка (Мессенджер / MAX / ВКонтакте / браузер и т.п.), тип ОС, случайный идентификатор устройства в локальном хранилище (для подсчёта уникальных устройств). Без имени, телефона и профиля;
- **обращения «Написать разработчику»:** текст сообщения и технические сведения, которые клиент площадки может передать вместе с запросом (например, идентификатор пользователя площадки, если он доступен), чтобы мы могли ответить;
- **служебные журналы** веб-сервера (IP, время, путь запроса) — в объёме, обычном для хостинга, для безопасности и отладки.

### 1.3. Данные площадок (ВКонтакте, Мессенджер, MAX)

При запуске мини-приложения площадка может передать параметры запуска (например, идентификатор пользователя и подпись). Мы используем их только для работы функций приложения и не продаём их третьим лицам. Обработка данных на стороне ВКонтакте / Мессенджера / MAX регулируется их собственными правилами.

### 1.4. Режим камеры и видео (если доступен)

Запись с камеры выполняется на устройстве. Файл может быть сохранён вами локально или передан средствами площадки (например, скачивание в клиенте ВК). Мы не ведём облачный видеохостинг пользовательских записей в составе обычного сценария приложения.

## 2. Для чего нужны данные

- работа метронома, настроек и связанных функций;
- понимание, на каких площадках и ОС открывают приложение (агрегированная статистика);
- ответы на обращения в поддержку;
- защита сервиса (лимиты запросов, расследование сбоев).

## 3. Передача третьим лицам

Мы не продаём персональные данные. Передача возможна только:

- хостинг-провайдеру инфраструктуры (хранение БД статистики и обработка HTTP-запросов);
- по требованию закона;
- когда вы сами инициируете действие через API площадки (например, сохранение файла в клиенте ВК).

## 4. Срок хранения

- статистика открытий — в пределах политики хранения на сервере (порядка года, затем удаление устаревших записей);
- обращения в поддержку — пока нужны для ответа и разбора, затем удаляются или обезличиваются;
- данные в localStorage — до очистки данных сайта / приложения вами.

## 5. Ваши возможности

- не пользоваться формой обратной связи;
- отключить учёт статистики на своём устройстве, открыв приложение один раз с параметром `?stats_exclude=1` (флаг сохранится в localStorage этого браузера / WebView);
- очистить данные сайта в настройках браузера / приложения;
- написать нам через **Написать разработчику** с просьбой о разборе обращения.

## 6. Дети

Приложение не предназначено для сбора данных детей. Если вы считаете, что нам передали данные ребёнка — напишите через форму в приложении.

## 7. Изменения

Актуальная версия публикуется на витрине проекта. Дата в начале документа обновляется при существенных правках.
