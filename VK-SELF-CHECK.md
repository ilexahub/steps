# STeps — самопроверка / ответ модератору (VK Mini Apps)

Краткий статус по [чек-листу тестирования](https://dev.vk.ru/ru/mini-apps/learning/course/5-testing/6-check-list) и гайду площадок.  
Приложение: **STeps** — визуальный метроном и тренажёр базовых шагов (музыкальный счёт 1…8, лента плашек).  
Версия продукта на момент подготовки: **5.6.1**.

Правовые документы:

- [Политика конфиденциальности](PRIVACY.md)
- [Условия использования](TERMS.md)

## Самопроверка по чек-листу

### Функциональные

| Пункт | Статус | Комментарий |
| --- | --- | --- |
| Онбординг | Не применимо | Нет первых экранов |
| Политика / условия | Сделано | Ссылки в настройках приложения и на витрине; указать те же URL в кабинете Mini App |
| Запросы прав | OK | Публичный флоу без scope |
| Нет сети | Частично | После загрузки метроном работает офлайн; каталог музыки и обратная связь нуждаются в сети |
| Deeplink | Частично | `vk.com/app…` / `m.vk.ru/app…`. До публикации в каталоге запуск часто идёт через веб-обёртку; нужна живая веб-сессия. После модерации ожидается стабильный вход из клиента / «Сервисы» |

### Основной флоу

| Пункт | Статус |
| --- | --- |
| Пользователь может тренироваться (Play / Stop / BPM / шаги / настройки) | OK — проверить руками |
| Форма «Написать разработчику» | OK |
| Share / истории / чаты / бонусы / акции | Не применимо |
| Камера, QR, полноэкранное видео (публично) | Не применимо |

### Нефункциональные

| Пункт | Статус | Комментарий |
| --- | --- | --- |
| Android | OK | Проверено |
| iOS | Прогнать | Код готов — нужен прогон на устройстве |
| vk.com | Прогнать | Desktop iframe |
| m.vk.com | Частично | Ок при живой сессии; без неё возможен пустой экран оболочки |
| Маленький экран | OK по вёрстке | Желательно iPhone SE-класс |
| Планшеты | OK | Контент ограничен шириной, без отдельной заглушки |
| Светлая / тёмная тема | OK | Синхрон с конфигурацией клиента; цвет подложки через `VKWebAppSetViewSettings` |
| Локализация | Частично | Только RU |
| Чистый / новый аккаунт | Прогнать | Связано с сессией оболочки до каталога |
| Подложка не чёрная/белая | OK | Цвет темы приложения |
| Ошибки на фронте | OK | Обратная связь, музыка, сеть |
| Текст не выделяется, иконки не кликабельны, кнопки без underline | OK |
| Swipe Back iOS | Прогнать | |
| ODR / вкладка «Сервисы» | После модерации | До каталога пункт не закрыть |

### Обновление данных (PullToRefresh и т.п.)

**Не применимо** для основного сценария: состояние в локальном хранилище устройства, без серверных «лутбоксов» и прогресс-баров. Каталог музыки обновляется при открытии листа выбора трека.

## Ручной прогон перед заявкой (минимум)

1. Android: открытие → Play → смена BPM → настройки → смена темы → «Написать разработчику» (можно не отправлять) → политика и условия открываются.  
2. Потянуть экран вниз: цвет подложки = фон приложения, не чёрный/белый.  
3. Авиарежим после загрузки: метроном играет.  
4. iOS и vk.com — те же шаги.  
5. Второй аккаунт / чистый: приложение открывается (после модерации — из каталога).  
6. В кабинете: URL во всех полях размещения; ссылки на политику и условия; оформление (иконка, обложка, сниппет) в светлой и тёмной теме.

## Одноклассники (план, не в этой заявке)

Площадка соседняя (тот же VK Bridge). Перед отдельной модерацией OK:

- привязать OK ID в кабинете («Другие площадки»);
- не уводить пользователя на внешние сайты из клиента OK (политика/условия — на своём домене или внутри приложения);
- в статистике и детектe отличать OK от ВК;
- платежи/реклама/share — не используются, адаптировать нечего.

Публикация OK — отдельный шаг после стабильного VK.
